## 定义

每次调用函数，运行时栈都会创建一个新的活动记录（Activation Record，也称栈帧）。访问链是活动记录中的一个指针，**它指向当前函数在词法作用域中的直接外层函数所对应的活动记录**。

> 访问链的主要用途：访问非局部变量（Non-local Variables）

注意区分：

|     | 动态链      | 访问链            |
| --- | -------- | -------------- |
| 依据  | 谁调用了我    | 我在谁的内部定义       |
| 作用  | 恢复调用者的栈帧 | 查找词法作用域中的非局部变量 |

## 维护

1. 如果调用的是直接嵌套在调用者内部的过程，被调用过程的访问链直接指向调用者的当前活动记录。
2. 递归调用时，新活动记录的访问链等于当前活动记录的访问链。
3. 如果被调用过程不是调用者的直接内部过程，就沿调用者的访问链向上，找到被调用过程的直接词法外层的活动记录。

> **无论谁调用谁，新活动记录的访问链永远指向被调用过程的直接词法外层过程所对应的活动记录。**

Q：如果不是直接调用，而是过程调用（即：把函数本身作为参数传递给另一个参数）呢？
A：同时传递函数的代码地址和==访问链==！

## 显示表

|比较项|访问链|显示表|
|---|---|---|
|数据结构|每个栈帧保存一个访问链指针|维护一个按词法深度索引的指针数组|
|访问外层变量|沿链逐层查找|直接读取 `d[i]`|
|查找复杂度|$O(k)$，k 为需要跨越的层数|$O(1)$|
|调用时维护|设置新栈帧访问链|保存旧表项并更新|
|返回时维护|随栈帧弹出自然失效|需要恢复旧表项|
