## 定义

边扫描边生成属性（On-the-fly Attribute Evaluation），更具体地说，就是不再等整棵语法树分析完毕之后才生成代码，而是在语法分析过程中直接把目标代码打印出来。

## 条件

1.   存在一个主属性，且主属性是综合属性
2.   在各产生式中，主属性是通过产生式体中各个非终结符号的主属性连接（并置）得到的，同时还会连接一些其它的元素
3.    各非终结符号的主属性的连接顺序和它在产生式体中的顺序相同

## 例子

对于SDT：

$$ \begin{aligned} S\rightarrow{}& \text{while }(\\ &\{L1=new();\ L2=new();\\ &\quad C.false=S.next;\\ &\quad C.true=L2;\\ &\quad print("label",L1);\}\\ &C)\\ &\{S_1.next=L1;\\ &\quad print("label",L2);\}\\ &S_1 \end{aligned} $$
就是一个边扫描边生成属性的例子。它的主要作用是把代码翻译成三地址代码。

递归下降程序可以写成：

```cpp
void S(label next) {
    label L1, L2;

    if (当前输入 == while) {
        读取输入;
        检查并读取 '(';

        L1 = new();
        L2 = new();

        print("label", L1);

        C(next, L2);

        检查并读取 ')';

        print("label", L2);

        S(L1);
    }
}
```
