> 数组引用翻译、类型转换，主要生成的是计算指令。但是编译器除了计算表达式，还需要决定下一条执行哪条指令。

## 相关的三地址指令

| 指令                              | 含义         |
| ------------------------------- | ---------- |
| `x = y op z`                    | 二元运算与赋值    |
| `goto L`                        | 无条件跳转到标签 L |
| `if x goto L`                   | x 为真则跳转    |
| `ifFalse x goto L`              | x 为假则跳转    |
| `if x relop y goto L`           | 关系条件成立时跳转  |
| `param x`、`call p,n`、`return y` | 过程调用和返回    |
| `x = y[i]`、`x[i] = y`           | 数组读写       |
| `x = &y`、`x = *y`、`*x = y`      | 地址和指针操作    |

## 布尔表达式

文法：

$$ \begin{aligned} B &\to B\ \|\|\ C\mid C\\ C &\to C\ \&\&\ D\mid D\\ D &\to !D\mid (B)\mid E\ \text{rel}\ E \mid \text{true}\mid\text{false} \end{aligned} $$

## 控制流语句翻译
### SDD

对于产生式：

$$ \begin{aligned} S&\to\text{if }(B)\ S_1\\ S&\to\text{if }(B)\ S_1\ \text{else }S_2\\ S&\to\text{while }(B)\ S_1 \end{aligned} $$

我们定义属性：

|属性|属性类别|含义|
|---|---|---|
|`B.code`|综合属性|布尔表达式生成的三地址代码|
|`S.code`|综合属性|语句生成的三地址代码|
|`B.true`|继承属性|布尔表达式为真时跳转的标签|
|`B.false`|继承属性|布尔表达式为假时跳转的标签|
|`S.next`|继承属性|当前语句执行结束后应该到达的标签|

示例：

```cpp
if (false) {
	x = 1;
}
```

这段程序涉及三条产生式：

$$ \begin{aligned} P&\to S\\ S&\to \text{if }(B)\ S_1\\ B&\to false \end{aligned} $$

先一步步求出各个`.true`和`.false`，再回溯拼接`.code`，最后可以得到：

```cpp
    goto L1

L2:
    x = 1

L1:
```

> 误区：LL 自顶向下分析（包括递归下降和非递归预测分析）以及 LR 自底向上分析，都可以在语法分析过程中同步生成中间代码，无须先构造语法树。
> 
> 但是：
>（1）LL 更适合 L 属性定义，因为可以在处理子节点之前传递继承属性。
>（2）LR 更适合 S 属性定义，因为在归约时可以直接根据子节点属性计算综合属性。
>（3）对于包含控制流继承属性的翻译方案，LR 可能需要使用中间语义动作、回填等方法；也可以选择先构造 AST，再进行语义翻译。
