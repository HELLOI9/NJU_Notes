## 类型

### 类型表达式

|类型|类型表达式|
|---|---|
|整数|`integer`|
|浮点数|`float`|
|长度为 10 的整数数组|`array[10, integer]`|
|长度为 3 的二维浮点数组（每行 4 个）|`array[3, array[4, float]]`|
|含 x、y 字段的记录|`record[(x,float),(y,integer)]`|
|整数到浮点数的函数|`integer → float`|

类型表达式并不是程序运行时要计算的普通表达式，它是在描述程序中某个数据对象的类型结构。

### 类型等价

1. 结构等价：两个类型的内部结构相同，就认为它们等价。
2. 名等价：即使两个类型的结构完全相同，只要它们是不同的独立命名类型，就不认为它们等价。

## 声明

### 声明文法

对于文法：

$$ \begin{aligned} D &\rightarrow T\ \mathrm{id}\ ;\ D\mid\epsilon\\ T &\rightarrow BC\mid\mathrm{record}\ \{\ D\ \}\\ B &\rightarrow\mathrm{int}\mid\mathrm{float}\\ C &\rightarrow\epsilon\mid[\mathrm{num}]C \end{aligned} $$

四个终结符分别表示：

| 符号  | 含义           | 负责什么               |
| --- | ------------ | ------------------ |
| $D$ | Declaration  | 表示一串变量声明           |
| $T$ | Type         | 表示完整的类型            |
| $B$ | Base Type    | 表示基本类型，如 int、float |
| $C$ | Array Suffix | 表示数组维度，可能为空        |

### 计算类型和宽度的SDT

```python
T → B
    { t = B.type; w = B.width; }
    C
    { T.type = C.type;
      T.width = C.width; }

B → int
    { B.type = integer;
      B.width = 4; }

B → float
    { B.type = float;
      B.width = 8; }

C → ε
    { C.type = t;
      C.width = w; }

C → [num] C₁
    { C.type = array(num.value, C₁.type);
      C.width = num.value * C₁.width; }
```

事实上，代码中的全局变量更加健硕的写法是使用继承属性与综合属性，定义：

$$ \begin{aligned} C.\mathrm{baseType}&=B.\mathrm{type}\\ C.\mathrm{baseWidth}&=B.\mathrm{width} \end{aligned} $$

对于：

$$ C\rightarrow[\mathrm{num}]C_1 $$

再将这些基本类型信息继续向下传递：

$$ \begin{aligned} C_1.\mathrm{baseType}&=C.\mathrm{baseType}\\ C_1.\mathrm{baseWidth}&=C.\mathrm{baseWidth} \end{aligned} $$

直到：

$$ C\rightarrow\epsilon $$

利用继承属性确定最内层的类型和宽度。

然后再通过综合属性 `type`、`width` 自底向上逐层包装数组。

### 声明序列的SDT

record的处理本质就是一个运行栈。

```python
T → record '{'
    {
        Env.push(top);
        top = new Env();

        Stack.push(offset);
        offset = 0;
    }
    D '}'
    {
        T.type = record(top);
        T.width = offset;

        top = Env.pop();
        offset = Stack.pop();
    }
```

其余的普通的$T$只需要把`offset`当作$D$的继承属性。

```python
P → { offset = 0; } D

D → T id ;
    {
        top.put(id.lexeme, T.type, offset);
        offset = offset + T.width;
    }
    D

D → ε
```


### 表达式代码SDD
|产生式|语义规则|
|---|---|
|$S\rightarrow\mathrm{id}=E;$|$S.code=E.code\parallel gen(top.get(id.lexeme)\;=\;E.addr)$|
|$E\rightarrow E_1+E_2$|$E.addr=newTemp()$|
||$E.code=E_1.code\parallel E_2.code\parallel gen(E.addr=E_1.addr+E_2.addr)$|
|$E\rightarrow-E_1$|$E.addr=newTemp()$|
||$E.code=E_1.code\parallel gen(E.addr=minus\ E_1.addr)$|
|$E\rightarrow(E_1)$|$E.addr=E_1.addr$|
||$E.code=E_1.code$|
|$E\rightarrow\mathrm{id}$|$E.addr=top.get(id.lexeme)$|
||$E.code=\epsilon$|

其中，$\parallel$ 表示代码序列拼接，$\epsilon$ 在这里表示空代码序列。

当然我们也可以用增量翻译的方案：

$$ \begin{aligned} S\rightarrow\;&\mathrm{id}=E;\\[-2pt] &\quad\{\,gen(top.get(id.lexeme)=E.addr);\,\} \\[10pt] E\rightarrow\;&E_1+E_2\\[-2pt] &\quad\{\,E.addr=newTemp();\\ &\qquad gen(E.addr=E_1.addr+E_2.addr);\,\} \\[10pt] E\rightarrow\;&-E_1\\[-2pt] &\quad\{\,E.addr=newTemp();\\ &\qquad gen(E.addr=minus\ E_1.addr);\,\} \\[10pt] E\rightarrow\;&(E_1)\\[-2pt] &\quad\{\,E.addr=E_1.addr;\,\} \\[10pt] E\rightarrow\;&\mathrm{id}\\[-2pt] &\quad\{\,E.addr=top.get(id.lexeme);\,\} \end{aligned} $$

| 对比项         | SDD           | 增量式 SDT         |
| ----------- | ------------- | --------------- |
| 属性          | `code`、`addr` | 仅 `addr`        |
| `gen()`     | 构造代码片段供拼接     | 直接向stdout序列追加指令 |
| 生成方式        | 自底向上构造代码序列    | 归约时直接发出指令       |
| 是否保存子表达式的代码 | 是             | 否               |
| 最终结果        | 三地址代码         | 三地址代码           |
