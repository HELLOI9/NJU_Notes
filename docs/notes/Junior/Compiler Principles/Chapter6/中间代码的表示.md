## 表示式

对于`a = b * c + d`，各种不同的表示形式：

1. 四元式：显式保存结果

|op|arg1|arg2|result|
|---|---|---|---|
|*|b|c|t1|
|+|t1|d|t2|
|=|t2|—|a|

优点：结果有独立名称，指令重排时不必因为位置变化而改写结果引用。缺点：中间结果需要使用一个临时变量保存。

2. 三元式：用指令编号表示结果

|编号|op|arg1|arg2|
|---|---|---|---|
|0|*|b|c|
|1|+|(0)|d|
|2|=|a|(1)|

优点：不需要显式临时结果字段。缺点：若编号由表中位置决定，指令移动后引用可能需要更新。

3. 间接三元式：额外增加执行指针表

|序号|指向|
|---|---|
|0|(0)|
|1|(1)|
|2|(2)|

|编号|运算|
|---|---|
|0|`* b c`|
|1|`+ (0) d`|
|2|`= a (1)`|

优点：通过修改指针表调整执行顺序，原三元式的编号和内容可以保持稳定。

## 静态单赋值(SSA)

### 定义

每个变量版本在程序中只能有一个赋值位置。通过引入$\phi$ 函数，根据程序从哪条控制流路径到达当前位置，选择对应路径提供的值。

### 例子
条件判断：

```cpp
if (flag)
    x1 = -1;
else
    x2 = 1;

x3 = φ(x1, x2);
y1 = x3 * a;
```

循环：

```cpp
Entry:
    x0 = 0
    goto Loop

Loop:
    x1 = φ(x0, x2)
    if x1 < 3:
        goto Body
    else:
        goto Exit

Body:
    x2 = x1 + 1
    goto Loop

Exit:
    print(x1)
```
