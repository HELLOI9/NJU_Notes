> 编译器不仅要知道 `E → E₁ + E₂` 的结果类型，还要确保 `E₁` 和 `E₂` 能够使用相应的机器指令进行运算。必要时，需要插入类型转换指令。

## 两种工作

- 类型综合：  根据子表达式的类型构造出表达式的类型。通常可以通过自底向上的综合属性计算实现。
- 类型推导：  根据语言结构的使用方式来确定该结构的类型，即根据程序中各个表达式之间的类型约束，反过来求出尚未确定的类型。

`widen`函数的简化实现：

```cpp
Addr widen(Addr a, Type t, Type w) {
    if (t == w)
        return a;

    else if (t == integer and w == float) {
        temp = new Temp();
        gen(temp '=' '(float)' a);
        return temp;
    }

    else
        error;
}
```
