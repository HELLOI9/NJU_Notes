> 编译器遇到 `a[i][j]` 时，如何根据数组的类型、元素宽度、下标表达式，计算出元素在内存中的位置，并生成三地址代码？

*编译器需要在语法分析的过程中，一边识别数组引用，一边计算字节偏移量。*

## 文法

$$ \begin{aligned} L&\to L[E]\\ L&\to id[E] \end{aligned} $$

其中：

- `id`：数组名，例如 `a`。
- `E`：下标表达式，例如 `i`、`j`、`i+1`。
- `L`：一个数组引用，例如 `a[i]` 或 `a[i][j]`。

## 翻译方案

| 属性        | 含义                          | 例子                     |
| --------- | --------------------------- | ---------------------- |
| `L.array` | 指向数组符号表条目的指针                | 数组 `a` 的符号表条目          |
| `L.type`  | 当前数组引用的结果类型                 | `a[i]` 是长度为 4 的 int 数组 |
| `L.addr`  | 存放当前数组引用字节偏移量的临时变量          | `t1 = i * 16` 中的 `t1`  |
| `E.addr`  | 存储表达式结果所在的位置，可以是变量名、临时变量名等。 | `i = 1`中的`i`           |
可以写出如下的制导方案：

```python
S → id = E ;    { gen(top.get(id.lexeme) '=' E.addr); }

  | L = E ;     { gen(L.array.base '[' L.addr ']' '=' E.addr); }


E → E₁ + E₂    { E.addr = new Temp();
                 gen(E.addr '=' E₁.addr '+' E₂.addr); }

  | id          { E.addr = top.get(id.lexeme); }

  | L           { E.addr = new Temp();
                  gen(E.addr '=' L.array.base '[' L.addr ']'); }


L → id [ E ]    { L.array = top.get(id.lexeme);
                  L.type = L.array.type.elem;
                  L.addr = new Temp();
                  gen(L.addr '=' E.addr '*' L.type.width); }

  | L₁ [ E ]    { L.array = L₁.array;
                  L.type = L₁.type.elem;
                  t = new Temp();
                  L.addr = new Temp();
                  gen(t '=' E.addr '*' L.type.width);
                  gen(L.addr '=' L₁.addr '+' t); }
```
