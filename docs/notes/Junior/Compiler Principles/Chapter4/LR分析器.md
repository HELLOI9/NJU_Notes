LR分析器是一个通用的框架，它描述的是：

```text
状态栈
+
输入
+
ACTION/GOTO 表
+
统一驱动程序
```

| 部分     | 列是什么               | 用途                                 |
| ------ | ------------------ | ---------------------------------- |
| ACTION | 终结符 `id,+,*,(,),$` | 决定 Shift / Reduce / Accept / Error |
| GOTO   | 非终结符 $E,T,F$       | 归约出一个非终结符以后决定进入哪个状态                |

在这个框架上，可以写出不同的LR方法：

|方法|状态信息/归约条件|
|---|---|
|LR(0)|只看 LR(0) 项，不看 lookahead|
|SLR(1)|LR(0) 项 + FOLLOW 集限制归约|
|LR(1)|LR(1) 项中直接带 lookahead|
|LALR(1)|合并部分 LR(1) 状态|
